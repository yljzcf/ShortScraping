ShortScraping 设置中心

这里用于维护网页订阅、定时任务、翻译接口和数据存档配置。配置文件按职责拆分，避免互相混用。

📄 配置文件

网页订阅、定时任务和翻译接口分别来自项目 config/ 目录下的独立 JSON 文件。扩展启动、刷新扩展或点击“重新读取配置”时，会从这些文件恢复配置。

  • 网页订阅：config/tag.json
  • 定时任务：config/cron.json
  • 翻译接口：config/trans.json
  • Lark 推送：config/lark.json
📌 当前配置概览
🌐 网页订阅

订阅规则来自规则目录 config/tag.example.json，标签随规则固定；勾选需要的订阅并保存，结果写入 config/tag.json。暂不支持自由添加 URL，新增规则请编辑目录文件后重载扩展。

规则目录为空或加载失败，请检查 config/tag.example.json。

说明：浏览器扩展不能直接写项目文件。保存时会先更新扩展本地配置，并尝试通过本地同步服务写回 config/tag.json；若同步服务未启动，会提示仅本地临时生效。

⏰ 定时任务

对应 config/cron.json。Cron 为 5 段格式：分钟 小时 日期 月份 星期，例如 45 * * * *。

🌍 翻译接口

对应 config/trans.json。这里只维护翻译接口、模型、提示词、批量大小、延迟和超时；定时任务请在 config/cron.json 中配置。

🔌 API 模式

免费 API 或兼容翻译接口。

🤖 AI 模式

AI 接口按 OpenAI 兼容 Chat Completions 格式调用，请妥善保管 API Key，避免提交真实密钥。

只需描述翻译风格/人设；翻译的输入输出 JSON 格式与批量对应关系由程序自动处理，无需在此约定格式。

🕊️ Lark 推送

对应 config/lark.json。时间线卡片上的 Lark 按钮会把卡片数据（条目 ID、中英文标题、简介、来源+标签、原站链接、封面链接）POST 到下方 Webhook 地址，「新增记录到多维表格」与「发送消息到话题群」由你的飞书工作流完成，消息模板随时可在飞书侧调整。

🛠️ 飞书侧配置指引
  • ① 建工作流：打开目标多维表格 → 左下角「工作流」→ 新建 → 触发器选「接收到 webhook 时」（增值功能，可用性与额度以界面提示为准；工作流与自动化共用每月运行次数），复制它提供的 Webhook 地址填到上方。
  • ② 捕获参数：点击下方「发送测试」发一条样例数据，让触发器识别参数结构。参数键固定为 item_id（全站点统一条目 ID，供核查对账：IMDB=tt…、Steam=appId、RoyalRoad=rr…、MyDrama=md…、ReelShort=rs…、DramaShorts=ds…、NetShort=ns…，值与本地 CSV 的 itemId 列一致） / title / title_zh / title_display / description / description_zh / summary / source / source_name / tags / url / poster / scraped_at / pushed_at，全部为字符串，空值为空字符串；tags 为英文逗号分隔，站点显示名（source_name）不含空格。
  • ③ 配动作：动作一选「新增记录」，把参数映射到表格字段（url / poster 建议用超链接字段）；动作二选「发送飞书消息」到目标话题群，消息内容可引用同批参数。
  • ④ 封面说明：webhook 推送本身只能传封面链接（外链图变飞书内真图需上传，平台限制）。表格内要真图附件——推荐用官方字段捷径「链接转附件」：表格中新建字段 → 「捷径」分类搜「链接转附件」→ 输入参数选「封面链接」列，添加后每条新记录自动转换，零开发、无需开任何面板。已知限制：该捷径解析不了含 @ 或百分号编码的 URL——dramashorts 封面推送时已自动解包为原始 CDN 直链（可转）；IMDB 封面（media-amazon 链接含 @）无法被捷径转换，IMDB 行无附件属预期，封面链接列仍可点击查看。群消息中的封面仍为链接，要卡片内真图需升级自建应用方案。

说明：保存时会先更新扩展本地配置，并尝试通过本地同步服务写回 config/lark.json；若同步服务未启动，会提示仅本地临时生效。「发送测试」使用当前表单草稿（无需先保存），发送时间线最新一条卡片数据，时间线为空时发送内置样例。
