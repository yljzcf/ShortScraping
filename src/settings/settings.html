了解更多

弹窗头部的站点图标按分组折叠，同一时间只展开一组；收起的分组压成一枚「‹ 图标 ›」胶囊。这里指定每组收起时显示哪个站点的图标——选「自动」则显示该组内最近有更新的站点。选中即保存，仅本机生效，不写入配置文件。

配置文件与写回说明

订阅、定时任务、翻译、飞书四类配置分别存在项目 config/ 目录下的独立 JSON 文件里：

  • 订阅：config/tag.json
  • 定时任务：config/cron.json
  • 翻译：config/trans.json
  • 飞书：config/lark.json

保存时先更新扩展本地配置，再经本地同步服务写回对应文件（浏览器扩展不能直接写项目文件）；同步服务没启动时本地配置保留，等它启动后（扩展下次唤醒时）自动写回。取消订阅例外：会删除该订阅下的历史，必须先写回文件成功才生效。

读取时扩展启动或刷新时从这些文件恢复配置（写回失败、仍待补写的配置以扩展里的为准）；点「重新读取配置」则一律以文件为准。文件读取或解析失败时沿用上一次的配置。

订阅规则来自规则目录 config/tag.example.json，标签随规则固定；暂不支持在这里自由添加 URL，新增规则请编辑目录文件后重载扩展。取消订阅会删除该订阅下的历史，必须先经同步服务写回文件成功才会生效；保存前会列出将删除的条数，确认后自动下载这批条目的 JSON 备份。

定时任务

按固定间隔或 Cron 表达式定时抓取与翻译。

5 段格式：分钟 小时 日期 月份 星期，例如 45 * * * *；支持 *、a-b、a,b,c、*/n。

默认 180，0 表示不限日期。改了天数后的第一轮 IMDb 只入库、不推送到飞书群。

了解更多

保存时会校验配置（非法 Cron 表达式拒绝保存）并立即重排定时任务。IMDb 订阅地址不写日期，抓取时按这里的天数只看近期发行的片，每个榜单读到的前 50 就是近期关注度最高的。

翻译接口

新卡片先以英文入库，再按这里的接口翻成中文。

API 模式免费 API 或兼容翻译接口
AI 模式OpenAI 兼容的 Chat Completions 接口

只需描述翻译风格 / 人设；输入输出的 JSON 格式与批量对应关系由程序处理。

高级参数：批量、超时、延迟

超时是上限而不是等待时长：推理型模型一批可能要几十秒，设太短会掐断整批、白花请求。API Key 请妥善保管，避免提交真实密钥。

多维表格工作流

卡片右上角的纸飞机把条目推到这个 Webhook，由飞书工作流写表、发消息。

飞书侧配置指引
  • ① 建工作流：打开目标多维表格 → 左下角「工作流」→ 新建 → 触发器选「接收到 webhook 时」（增值功能，可用性与额度以界面提示为准；工作流与自动化共用每月运行次数），复制它提供的 Webhook 地址填到上方。
  • ② 捕获参数：点「发送测试」发一条样例数据，让触发器识别参数结构。参数键固定为 item_id（全站点统一条目 ID，供核查对账：IMDB=tt…、Steam=appId、RoyalRoad=rr…、MyDrama=md…、ReelShort=rs…、DramaShorts=ds…、NetShort=ns…、Netflix=nf…、AppleTV=at…、FlickReels=fr…、GoodShort=gs…、Shortical=sc…、ShortMax=sm…、DramaBox=db…、PinesDramas=pdd…/pdn…、Higgsfield=hf…，值与本地 CSV 的 itemId 列一致） / title / title_zh / title_display / description / description_zh / summary / source / source_name / tags / genres / url / poster / scraped_at / pushed_at，全部为字符串，空值为空字符串；tags 与 genres 为英文逗号分隔（genres＝站点原生内容类型标签，英文原值，v1.5.3 新增），站点显示名（source_name）不含空格。此前已配好的工作流要引用新增的 genres 参数，需重新点一次「发送测试」让触发器重新捕获参数结构（不重捕获也不影响原有运行，只是引用不到新参数）。
  • ③ 配动作：动作一选「新增记录」，把参数映射到表格字段（url / poster 建议用超链接字段）；动作二选「发送飞书消息」到目标话题群，消息内容可引用同批参数。
  • ④ 封面说明：webhook 推送本身只能传封面链接（外链图变飞书内真图需上传，平台限制）。表格内要真图附件——推荐用官方字段捷径「链接转附件」：表格中新建字段 → 「捷径」分类搜「链接转附件」→ 输入参数选「封面链接」列，添加后每条新记录自动转换，零开发、无需开任何面板。已知限制：该捷径解析不了含英文逗号或百分号编码的 URL——推送时已按站点自动规避：dramashorts 解包为原始 CDN 直链、IMDB 改写为无逗号的原图形态、FlickReels 去掉含逗号的 OSS 缩放参数还原原图、Higgsfield 换成不带百分号编码的 1080 宽大图，均可正常转换；若个别行仍失败，多为链接含其他特殊字符（如 NetShort 文件名中的全角冒号），属捷径解析限制。群消息中的封面仍为链接，要卡片内真图需升级自建应用方案。
群机器人实时推送

新内容翻译完成后自动推一张卡片到群。免费，不占工作流的每月运行次数。

封面图（可选）填飞书自建应用凭据后卡片带真封面图，留空发无图卡
了解更多：怎么拿 Webhook、推送与重试规则、封面凭据

在目标群「设置 → 群机器人 → 添加自定义机器人」拿到 Webhook 地址填入即可，安全设置留空或按需配置。只有频率限流：单机器人 100 次/分钟、5 次/秒，扩展已按 250ms 间隔自动节流。推的是群消息不是表格记录，两条通道各管各的：表格数据仍走卡片右上角的纸飞机按钮与「数据」页的批量导出。

启用水位线：开启开关的那一刻会记下时间，只推这之后新抓到的条目——否则库里几千条存量陆续翻译完会在群里刷屏。关闭开关即清除水位线，下次开启重新计时。推送失败会自动重试：先推完同批次其他卡，之后最多重试 3 次、每次间隔 1 分钟（队列存在本地，用扩展闹钟驱动，浏览器关闭期间暂停、重开后继续），仍失败则丢弃并记日志；全程不影响抓取与翻译落库。

封面凭据：卡片里的图必须是 img_key，外链 URL 塞不进去（会被整条拒收，ErrCode 11310）。填入飞书自建应用的凭据后，扩展会在推送前把封面上传到飞书换取 img_key，卡片即可带真封面图（满宽原样，不裁不缩）。这不是第二条推送通道——推送目标仍由上面的 Webhook 地址决定；img_key 跨云可用，在飞书租户上传的图推到 Lark 国际版群里也能正常显示（2026-09-12 实测）。两个字段都填才带图。应用需在开放平台创建并开通 im:resource（上传图片）权限后发布版本。上传失败会自动降级发无图卡，不会因此丢掉推送。

工作流、群机器人与封面凭据一起保存到 config/lark.json。
导出与恢复

JSON 备份可导入恢复；CSV 只给表格软件看，不能回导。

了解更多

导入按条目 ID 去重——已存在的条目跳过不覆盖，订阅范围之外的条目不会导入。扩展按订阅范围自动清理历史（取消订阅、按 config/tag.json 回读订阅等）前，会把被删条目存进「自动清理回收站」（只保留最近 3 批）；回收站有内容时才显示导出按钮，导出的文件同样用「导入 JSON 恢复」写回，恢复前要先把对应订阅加回来。

导出到多维表格

把增量复制成表格格式，在多维表格表末第一个空行的首格按 Ctrl+V 追加。

了解更多

复制的是纯数据行、不含表头，列序与 npm run export-lark 导入建表时完全一致，封面链接已改写成官方「链接转附件」捷径能解析的形态。增量按入库时间计（「导入恢复」补回的条目按原抓取时间，不当新条目重导）：只勾部分站点复制时，各站分别记住自己的上次复制时间，没勾的站点不受影响；复制时还没翻译完的条目照常导出（中文列为空或不全），译文完成后不会自动补发。存量首次灌表走 npm run export-lark 导出文件再导入——条数太多不适合走剪贴板。
