ShortScraping 设置中心

这里用于维护网页订阅、定时任务、翻译接口和数据存档配置。配置文件按职责拆分，避免互相混用。

📄 配置文件

网页订阅、定时任务和翻译接口分别来自项目 config/ 目录下的独立 JSON 文件。扩展启动、刷新扩展或点击“重新读取配置”时，会从这些文件恢复配置。

  • 网页订阅：config/tag.json
  • 定时任务：config/cron.json
  • 翻译接口：config/trans.json
  • Lark 推送：config/lark.json
📌 当前配置概览
🗂️ 分组图标

弹窗头部的站点图标按分组折叠，同一时间只展开一组；收起的分组压成一枚「‹ 图标 ›」胶囊。这里指定每组收起时显示哪个站点的图标——选「自动」则显示该组内最近有更新的站点。选中即保存，仅本机生效，不写入配置文件。

🌐 网页订阅

订阅规则来自规则目录 config/tag.example.json，标签随规则固定；勾选需要的订阅并保存，结果写入 config/tag.json。暂不支持自由添加 URL，新增规则请编辑目录文件后重载扩展。

规则目录为空或加载失败，请检查 config/tag.example.json。

说明：浏览器扩展不能直接写项目文件。保存时会先更新扩展本地配置，并尝试通过本地同步服务写回 config/tag.json；若同步服务未启动，会提示仅本地临时生效。

⏰ 定时任务

对应 config/cron.json。Cron 为 5 段格式：分钟 小时 日期 月份 星期，例如 45 * * * *（支持 *、a-b、a,b,c、*/n）。

说明：保存时会校验配置（非法 Cron 表达式拒绝保存）、更新扩展本地配置并立即重排定时任务，再尝试通过本地同步服务写回 config/cron.json；若同步服务未启动，写回失败的配置会在扩展下次重启时被文件中的旧配置覆盖。

🌍 翻译接口

对应 config/trans.json。这里只维护翻译接口、模型、提示词、批量大小、延迟和超时；定时任务请在 config/cron.json 中配置。

🤖 AI 模式

只需描述翻译风格/人设；翻译的输入输出 JSON 格式与批量对应关系由程序自动处理，无需在此约定格式。

🕊️ Lark 推送

对应 config/lark.json。时间线卡片上的 Lark 按钮会把卡片数据（条目 ID、中英文标题、简介、来源+标签、内容类型标签、原站链接、封面链接）POST 到下方 Webhook 地址，「新增记录到多维表格」与「发送消息到话题群」由你的飞书工作流完成，消息模板随时可在飞书侧调整。

🛠️ 飞书侧配置指引
  • ① 建工作流：打开目标多维表格 → 左下角「工作流」→ 新建 → 触发器选「接收到 webhook 时」（增值功能，可用性与额度以界面提示为准；工作流与自动化共用每月运行次数），复制它提供的 Webhook 地址填到上方。
  • ② 捕获参数：点击下方「发送测试」发一条样例数据，让触发器识别参数结构。参数键固定为 item_id（全站点统一条目 ID，供核查对账：IMDB=tt…、Steam=appId、RoyalRoad=rr…、MyDrama=md…、ReelShort=rs…、DramaShorts=ds…、NetShort=ns…、Netflix=nf…、AppleTV=at…、FlickReels=fr…，值与本地 CSV 的 itemId 列一致） / title / title_zh / title_display / description / description_zh / summary / source / source_name / tags / genres / url / poster / scraped_at / pushed_at，全部为字符串，空值为空字符串；tags 与 genres 为英文逗号分隔（genres＝站点原生内容类型标签，英文原值，v1.5.3 新增），站点显示名（source_name）不含空格。此前已配好的工作流要引用新增的 genres 参数，需重新点一次「发送测试」让触发器重新捕获参数结构（不重捕获也不影响原有运行，只是引用不到新参数）。
  • ③ 配动作：动作一选「新增记录」，把参数映射到表格字段（url / poster 建议用超链接字段）；动作二选「发送飞书消息」到目标话题群，消息内容可引用同批参数。
  • ④ 封面说明：webhook 推送本身只能传封面链接（外链图变飞书内真图需上传，平台限制）。表格内要真图附件——推荐用官方字段捷径「链接转附件」：表格中新建字段 → 「捷径」分类搜「链接转附件」→ 输入参数选「封面链接」列，添加后每条新记录自动转换，零开发、无需开任何面板。已知限制：该捷径解析不了含英文逗号或百分号编码的 URL——推送时已按站点自动规避：dramashorts 解包为原始 CDN 直链、IMDB 改写为无逗号的原图形态、FlickReels 去掉含逗号的 OSS 缩放参数还原原图，均可正常转换；若个别行仍失败，多为链接含其他特殊字符（如 NetShort 文件名中的全角冒号），属捷径解析限制。群消息中的封面仍为链接，要卡片内真图需升级自建应用方案。

说明：保存时会先更新扩展本地配置，并尝试通过本地同步服务写回 config/lark.json；若同步服务未启动，会提示仅本地临时生效。「发送测试」使用当前表单草稿（无需先保存），发送时间线最新一条卡片数据，时间线为空时发送内置样例。

🤖 群机器人实时推送

另一条独立且免费的通道：新内容翻译完成后自动推一张卡片到群，不消耗多维表格工作流的每月运行次数（只有频率限流：单机器人 100 次/分钟、5 次/秒，扩展已按 250ms 间隔自动节流）。在目标群「设置 → 群机器人 → 添加自定义机器人」拿到 Webhook 地址填入即可，安全设置留空或按需配置。
推的是群消息不是表格记录，两条通道各管各的：表格数据仍走卡片上的 🕊 按钮与「数据存档」里的批量导出。推送失败会自动重试：先推完同批次其他卡，之后最多重试 3 次、每次间隔 1 分钟，仍失败则丢弃并记日志，全程不影响抓取与翻译落库。

🖼️ 封面图上传（飞书开放平台凭据）

卡片里的图必须是 img_key，外链 URL 塞不进去（会被整条拒收，ErrCode 11310）。填入飞书自建应用的凭据后，扩展会在推送前把封面上传到飞书换取 img_key，卡片即可带真封面图（满宽原样，不裁不缩）。
这不是第二条推送通道——推送目标仍由上面的 Webhook 地址决定；img_key 跨云可用，在飞书租户上传的图推到 Lark 国际版群里也能正常显示（2026-09-12 实测）。
两个字段都填才带图，留空就发无图卡。应用需在开放平台创建并开通 im:resource（上传图片）权限后发布版本。上传失败会自动降级发无图卡，不会因此丢掉推送。

启用水位线：开启开关的那一刻会记下时间，只推这之后新抓到的条目——否则库里几千条存量陆续翻译完会在群里刷屏。关闭开关即清除水位线，下次开启重新计时。推送失败会自动重试（最多 3 次、每次间隔 1 分钟；队列存在本地，用扩展闹钟驱动，浏览器关闭期间暂停、重开后继续），仍失败则丢弃并记日志；全程不影响抓取与翻译落库。

📦 导出与恢复

JSON 备份包含全部条目、可导入恢复；CSV 仅供表格软件查看，不支持回导。导入按条目 ID 去重——已存在的条目跳过不覆盖，订阅范围之外的条目不会导入。

📤 导出到多维表格

把增量复制成表格格式，切到多维表格里选中表末第一个空行的首个单元格，按 Ctrl+V 直接追加。复制的是纯数据行、不含表头，列序与 npm run export-lark 导入建表时完全一致，封面链接已改写成官方「链接转附件」捷径能解析的形态。
存量首次灌表走 npm run export-lark 导出文件再导入——条数太多不适合走剪贴板。

🧹 按条件清理

勾选站点后先「预览命中数」，确认无误再删除；删除会同步反映到时间线与 CSV，不可撤销——建议清理前先导出 JSON 备份（误删可导回）。
